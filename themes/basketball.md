# 테마: 농구공 (`basketball`)

> 이 파일은 이 테마 세션이 **작업하면서 직접 갱신**한다.

- **브랜치 / 폴더**: `theme/basketball` / `../ThrowMe-basketball`
- **enum**: `SlimeSkinKind.Basketball = 5`
- **설정창 표시 이름**: `"농구공"`
- **상태**: 🔀 머지됨 (`main` 통합 완료)

## 1. 컨셉 / 디자인
- 주황 구체 + 검정 씸(seam) 무늬의 농구공. 단단한 공(**Rigid**, 찌그러지지 않음).
- **중력**: 농구공일 때만 아래로 떨어진다(`GravityY`). 바닥(작업영역 하단)에 안착하면 정지→렌더 루프 유휴(CPU 0). 다른 스킨은 무중력 유지.
- **튈 때마다 무늬가 바뀐다**: 정통 농구공 무늬(세로선+가로선+양옆 곡선)를 벽/골대 충돌·득점마다 임의 회전 + 곡선 폭 변형 → 참고 이미지의 9개 방향처럼 매번 다른 모양.
- **농구 골대**: 농구공일 때만 우클릭 메뉴에 `농구골대 구현`이 보이고, 누르면 **가장 왼쪽 / 가장 오른쪽 모니터**에 골대(기둥+지지대+빨간 수평 림+다이아몬드 그물)가 생긴다. 참고 이미지(`image/골대.png`) 기반.
- **골 넣기(위→아래)**: 중력으로 떨어지는 공을 수평 림 개구부로 **위에서 아래로 통과**시키면 득점(림 폭 > 공 지름이라 정중앙 통과 가능). 득점 시 그물이 파도치며 펄럭이고 림 뒤 섬광 + 스위시 효과음.
- **빨간 림/백보드 충돌**: 빨간 림 양 끝(앞/뒤 가장자리)과 넓은 백보드는 단단한 충돌체 → 빗맞으면 공이 튕긴다(클랭크). 충돌 시 그물도 흔들린다.
- **현실 물리 잠금(골대 ON일 때만)**: 골대를 켜면 물리를 고정(사용자 설정 슬라이더 무시) — 반발 0.62, 낮은 공기저항, 바닥 구름 마찰, 중력 2200. 골대를 끄면 사용자 설정으로 복귀(중력은 농구공이면 유지).
- **던지기(골대 ON일 때만)**: 당구 큐처럼 공을 잡고 **뒤로 끌면 앞쪽에 유도선**이 나오고, **놓으면 그 방향으로 발사**(끈 거리 = 파워, 상한 3000, 살살). 큐대는 없이 유도선만. 조준 중에는 공이 중력으로 떨어지지 않게 정지.
- **펄럭이는 그물(완화)**: 노드-연결 스프링(위 노드·이웃 가닥) + 가닥별 무작위 킥으로 파도치듯 흔들리되, 킥 상한·변위 상한(0.35S)으로 **림까지 치솟지 않게** 절제.
- **점수판(교차 채점)**: 각 골대 모니터 **최상단**에 점수판. **왼쪽 골대가 먹히면 오른쪽 점수판 +**, 오른쪽 골대가 먹히면 왼쪽 점수판 +. 단일 모니터면 두 점수판을 좌/우로 벌려 배치.

## 2. 만든 / 수정한 파일

- `Views/SlimeWindow.xaml.cs` → `ApplySkin()` case, `UpdateSkinBehavior()`에 중력 설정, 골대/점수판/득점 통합

- 스킨 변경/모니터 구성 변경/종료 시 골대 정리·재배치.

## 3. 구현 메모
- 씸은 96 캔버스(여백6) 안 84×84, 중심(42,42)·반경 40에 **지름 선(대원) + 타원 외곽선(경선/위선)** 조합으로 그린다. 좁은 세로타원이 "양옆 두 곡선"으로 보이는 걸 이용해 정면 농구공 무늬를 구성. 전체 회전/반전으로 변형을 무한히 만든다.
- 골대는 **px 캔버스 + `Viewbox Stretch=Fill`** 로 그려 DPI에 무관하게 물리 픽셀 좌표로 배치. 득점 판정용 `RimCenter`/`ScoreRadius`/`ScoreDirX`(물리 px)만 SlimeWindow에 노출.
- 그물: 림(고정) 아래 5링×10가닥 원뿔. 자유 노드는 스프링(-kx) + 감쇠(-cv) 적분, 득점 시 공속도 기반 임펄스(깊을수록 크게 + 아래로). 다이아몬드 메시를 `StreamGeometry`로 매 프레임(움직일 때만) 재구성. 정지 시 재생성 생략 → 유휴 0 부담.
- 중력이 없는 엔진이라 득점은 "벽 쪽으로 림 통과"로 정의(측면 뷰 골대). `WasInZone`으로 중복 득점 방지.
